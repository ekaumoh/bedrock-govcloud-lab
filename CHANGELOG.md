# Changelog

All notable changes to this project are documented here. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-20

### Added
- Partition-aware lab scripts for preflight, smoke test, VPC endpoints, least-privilege IAM, invocation logging, guardrails, Knowledge Base sync and canary checks, cleanup, and verification.
- Python examples: Converse and streaming, retrieve-then-generate RAG with citations, allow-listed tool use.
- Terraform for a versioned guardrail, a one-model invoke policy, and a private, encrypted invocation-logging stack.
- GovCloud do-not-forgets and lessons-learned documentation.
- CI: ShellCheck, Ruff, Terraform validate, gitleaks, and a real-account-ID guard.
